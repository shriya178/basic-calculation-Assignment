# TypeScript Assignment Programs

This repository contains TypeScript programs based on basic programming concepts such as conditional statements, switch statements, operators, and calculations.

## Programs Included

### Conditional Statements (if, if-else, nested if)

1. Even or Odd Number Checker
2. Positive, Negative, or Zero Checker
3. Larger of Two Numbers
4. Largest Among Three Numbers
5. Smallest Among Three Numbers
6. Student Grade Calculator
7. Electricity Bill Calculator
8. Simple Interest Calculator
9. Employee Net Salary Calculator
10. Voting Eligibility Checker
11. Leap Year Checker
12. Number Range Checker
13. Student Result System

### Number Operations

14. Swap Two Numbers (Using Third Variable)
15. Swap Two Numbers (Without Third Variable)
16. Maximum of Two Numbers Using Ternary Operator

### Switch Statement Programs

17. Calculator Using Switch Statement
18. Month Name Display
19. Day Name Display

### Validation Programs

20. Password Validation
21. Login Credential Validation

## Technologies Used

- TypeScript
- Node.js

## How to Run

Compile the TypeScript file:

```powershell
tsc filename.ts
```

Run the JavaScript file:

```powershell
node filename.js
```
